# First-week checklist

## Day 1 — Get running
- [ ] Access: GitHub org/team membership, Copilot license, SSO, chat channels
- [ ] Toolchain verified (`check-toolchain.mjs`) or dev container / Codespace opened
- [ ] Project installed, running locally, and tests passing
- [ ] Copilot plugins installed: **onboarding-buddy**, **secure-code**, **ship-ready**
- [ ] Read the README and architecture docs; ask the onboarding-buddy agent to walk one request end to end

## Day 2 — Understand
- [ ] Explore the main domain entities and API routes
- [ ] Read the repository's Copilot instructions (`.github/copilot-instructions.md`, `.github/instructions/`)
- [ ] Find the code owners for the areas you'll work in (`who_owns`)
- [ ] Learn the team's branch, PR, and review conventions (CONTRIBUTING)

## Day 3 — First contribution
- [ ] Pick a starter task (`suggest_first_tasks` or a `good first issue`)
- [ ] Create a branch, make the change with tests, run `/security-scan`
- [ ] Open a pull request and respond to review

## Days 4–5 — Level up
- [ ] Ship the first PR 🎉
- [ ] Shadow a release (`/ship-check`) and an on-call handoff
- [ ] Improve one onboarding doc gap you noticed
- [ ] 1:1 with your onboarding buddy: what was confusing? Capture it in the docs
